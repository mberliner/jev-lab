# Perfiles de usuario

Los perfiles a los que cada feature entrega valor (Constitución §VII). Cada spec declara su persona
principal en la sección «Corte vertical y lección».

| Perfil | Quién es | Cómo usa jev-lab |
| --- | --- | --- |
| **Usuario inicial de Jev** | Desarrollador que empieza a usar Jev y aprende a decidir con él | Con la CLI y las lecciones |
| **Operador** | Persona que atiende la cola de revisión y ajusta umbrales | Con la CLI, la política versionada y los informes |
| **Integrador** | Desarrollador de otro sistema | Consume la API |
| **Mantenedor de jev-lab** | Persona o agente que cambia el propio proyecto | Con Spec Kit, los agentes, pre-commit y CI |

Un perfil nuevo se añade aquí antes de usarlo en una spec.
